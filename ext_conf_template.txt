# mindtwo Monitoring — non-secret settings only.
#
# The project key and the secret are read from the environment (MONITORING_PROJECT_KEY,
# MONITORING_SECRET) and are deliberately not configurable here: settings.php is versioned and
# deployed to every stage, and the extension configuration form has no password field.
#
# Every field is empty by default. Empty = inherit the matching MONITORING_* environment
# variable, then the built-in default. TYPO3 writes template defaults into settings.php, so a
# non-empty default here would permanently shadow the environment.
#
# Every subcategory must be registered with customsubcategory, otherwise TYPO3 13 files it under
# "Other", where entries with the same sorting number overwrite each other.
